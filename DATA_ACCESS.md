# Request access to the derived tracks

Email [20241513028@edu.sspu.cn](mailto:20241513028@edu.sspu.cn) with the subject **KA-Diff dataset access request**. Include your name, affiliation, intended research use, and the detector variant you need (HRNet-W48, ViTPose-H, or both). Both detector variants support the controlled and natural-error protocols.

Requests are reviewed by the authors. If access is approved, the authors will provide the versioned files and delivery instructions through an authorized channel. Approval and delivery are subject to the PoseTrack21 data access terms. This repository provides no anonymous download link for the track archives.

The archives pair each detector's pose tracks with its matching normalization statistics. Use the supplied SHA-256 checksums to verify transferred files. Only load PKL files obtained through the authorized delivery channel.

This access process does not provide the original video frames or a standalone copy of the official annotation packages. Obtain those through the [official PoseTrack21 access process](https://github.com/anDoer/PoseTrack21#how-to-get-the-dataset).
